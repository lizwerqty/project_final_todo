# Планировщик задач (Go Final Project)

## Описание проекта

Веб-приложение для управления задачами с поддержкой повторений. Приложение позволяет создавать, редактировать, удалять и выполнять задачи, а также автоматически рассчитывать следующую дату выполнения.

Поддерживаются следующие правила повторения:

* ежедневно (d)
* ежегодно (y)
* по дням недели (w)
* по дням месяца (m)

## Выполненные задания повышенной сложности

Реализована поддержка правил повторения:

* w — дни недели
* m — дни месяца

Реализована аутентификация с использованием JWT-токенов.

Добавлен middleware для защиты API.

Создан Dockerfile для контейнеризации приложения.

## Запуск проекта локально

При необходимости можно задать переменные окружения:

```bash
export TODO_PASSWORD=12345
export TODO_PORT=7540
export TODO_DBFILE=scheduler.db
```

Если переменная TODO_PASSWORD не задана, приложение работает без авторизации.

Для запуска сервера выполните команду:

```bash
go run .
```

После запуска приложение будет доступно по адресу:
http://localhost:7540

## Аутентификация

Если переменная TODO_PASSWORD не задана, API доступен без авторизации.

Если переменная задана, требуется выполнить вход через эндпоинт /api/signin.

Пример запроса:

```bash
curl -X POST http://localhost:7540/api/signin \
  -H "Content-Type: application/json" \
  -d '{"password":"12345"}'
```

В ответ возвращается JWT-токен, который используется через cookie с именем token.

## Запуск тестов

Перед запуском тестов необходимо указать токен в файле tests/settings.go:

```go
Token = "ваш JWT токен"
```

После этого выполнить:

```bash
go test ./tests
```

## Сборка и запуск через Docker

Сборка Docker-образа:

```bash
docker build -t go_final_project .
```

Запуск контейнера:

```bash
docker run -d \
  -p 7540:7540 \
  -v $(pwd)/scheduler.db:/data/scheduler.db \
  -e TODO_PASSWORD=12345 \
  go_final_project
```

После запуска приложение будет доступно по адресу:
http://localhost:7540

## Структура проекта

pkg/api — обработчики API
pkg/db — работа с базой данных
pkg/server — запуск HTTP-сервера
web — фронтенд
tests — тесты

## Особенности реализации

Используется SQLite (modernc.org/sqlite)
Аутентификация реализована с помощью JWT-токенов
Для защиты API используется middleware
Поддерживаются переменные окружения для конфигурации приложения
Проект упакован в Docker-контейнер
